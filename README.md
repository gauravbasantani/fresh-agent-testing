# How I test AI with fresh agents

AI output can look finished and still be wrong. This page explains how I test AI work with fresh
AI agents that have never seen it, and what two studies found, with real numbers only:

- LIVE, an AI video workspace at ASU's Learning Engineering Institute (three-designer project;
  I wrote the instructions and skills). Method and results only; the code is private.
- Proposal kit, a tiny design system I designed and directed Claude Code to build. The eval's
  prompts, logs and counts: https://github.com/gauravbasantani/proposal-kit/tree/main/evals

- Page: https://gauravbasantani.github.io/fresh-agent-testing/

One static HTML file, no build step.
